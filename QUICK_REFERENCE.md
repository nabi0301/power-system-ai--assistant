# 💡 AI Suggestions Quick Reference

## One-Click Access
**Location:** Chat interface → 💡 (Golden lightbulb button)

---

## What You Get

### 🔮 Predictive Analysis
**Warns you about:**
- Lines at 80-90% (will fail soon)
- Buses near voltage limits
- Risk scenarios (load increase, outages)

**Example:**
> "⚠️ Branch 15→17 at 87.3% - Only 12.7% margin before violation!"

---

### ⚡ Optimization
**Tells you how to fix issues:**
- Redispatch generators (which buses, how much MW)
- Reduce concentrated loads (specific MW amounts)
- Add reactive support (which buses, how much MVAR)

**Example:**
> "Shift 30.6 MW from Bus 10 to Bus 42 to fix line overload"

---

### 🔄 Case Comparisons
**Suggests comparisons:**
- Base vs Contingency
- All contingencies ranked
- SLR vs DLR
- Pattern analysis

**Example:**
> "Compare base case with Contingency 1 to see first outage impact"

---

### ⚙️ Custom Preferences
**Adapts to your view:**
- Voltage view → Focus on voltage issues
- Loading view → Focus on thermal limits
- Violations view → Focus on fixes

**Example:**
> "You're viewing Violations - Next step: Check Network View"

---

## Quick Commands

Ask the AI:
- `"Focus on voltage issues only"`
- `"Show optimization opportunities"`
- `"Compare all cases"`
- `"What will fail if load increases?"`
- `"Quick summary of problems"`

---

## Typical Output Structure

```
💡 Smart Suggestions for Case X

1. Current Issues (if any)
   - Violations
   - Voltage problems
   - Critical loading

2. 🔮 Predictions
   - Lines approaching limits
   - Future violation risks

3. ⚡ Optimizations
   - Redispatch recommendations
   - Load management
   - Reactive power fixes

4. 🔄 Comparisons
   - Available cases
   - Suggested comparisons

5. ⚙️ Preferences
   - Current view context
   - Next steps
   - Custom options
```

## Pro Tips

✅ **Use after every case change** - Get updated analysis
✅ **Follow visualization suggestions** - Auto-switches to relevant views
✅ **Ask follow-up questions** - "Why is Bus 42 low voltage?"
✅ **Compare suggestions across cases** - See patterns

## Emergency Quick Actions

**If you see violations:**
1. Click 💡 for suggestions
2. Follow "Immediate Action Required"
3. Switch to suggested view
4. Ask for detailed fix

**If system is healthy:**
1. Click 💡 for insights
2. Review predictive warnings
3. Check comparison suggestions
4. Explore optimization opportunities
