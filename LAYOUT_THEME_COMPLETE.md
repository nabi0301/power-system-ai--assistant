## 💡 How to Customize Further

### Change a Box Color
Find the section and modify:
```python
style={
    "backgroundColor": "rgba(0, 20, 40, 0.85)",  # Change RGB values
    "border": "1px solid rgba(0, 255, 255, 0.3)", # Change border color
    "boxShadow": "0 0 20px rgba(0, 255, 255, 0.2)" # Change glow color
}
```

### Change Text Color
```python
style={
    "color": "#e0e0e0"  # Change to any color
}
```

### Adjust Transparency
```python
"backgroundColor": "rgba(0, 20, 40, 0.85)"
                                    ↑
                    Change this (0.0 = invisible, 1.0 = solid)
```

### Adjust Glow Intensity
```python
"boxShadow": "0 0 20px rgba(0, 255, 255, 0.2)"
                    ↑                      ↑
              Blur radius              Opacity
```
